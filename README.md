# AI Security Risk & Defense Sandbox

This project demonstrates how to identify security vulnerabilities in AI text inputs and apply technical risk management frameworks.

### Key Concepts Covered:
* **Inherent vs. Residual Risk:** Quantifying raw risk and leftover risk after security controls are applied.
* **Threat Actors:** Handling both intentional (hackers) and unintentional (employee mistakes) data threats.
* **Defense Lifecycle:** Implementing input sanitization (**Prevention**), automated logging (**Detection**), and secure error handling (**Mitigation**).
